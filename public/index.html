Event-Driven Asynchronous Badge Printing Prototype

📍 GTC Convention Centre, Westlands, Nairobi, Kenya
💡 Synchronous ➔ Asynchronous Architecture Pivot

Decouples attendee check-in requests from slow physical badge printers. Returns HTTP 202 Accepted instantly while an asynchronous queue dispatches thermal badge print jobs and receives webhook completion callbacks.

Step 1
Kiosk Scan
POST /api/check-in validates duplicate scan lock & returns 202 Accepted.
Step 2
Async Print Queue
Status set to PENDING_PRINT; print task queued in background.
Step 3
Status Polling
Kiosk polls GET /api/status?id=... every 1s asynchronously.
Step 4
Print Complete
Webhook POST /api/webhooks/print-complete updates state to CHECKED_IN.
