Solstice Check-In Kiosk Async Queue

Event-Driven Serverless Badge Printing Prototype

💡 Synchronous ➔ Asynchronous Architecture Pivot

Decouples user check-in requests from slow physical badge printing hardware. Returns HTTP 202 Accepted instantly while an asynchronous queue updates status via webhooks.

Step 1
Scan / Check-In
POST /api/check-in checks duplicate state and returns 202 Accepted.
Step 2
Async Queue Job
Status set to PENDING_PRINT; print job dispatched asynchronously.
Step 3
Status Polling
Kiosk polls GET /api/status?id=... every 1s without blocking threads.
Step 4
Print Confirmation
Webhook POST /api/webhooks/print-complete updates status to CHECKED_IN.
